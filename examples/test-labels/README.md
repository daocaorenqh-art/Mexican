# 真机测试标签

用 `node tests/make-test-labels.cjs` 生成；`tests/e2e/testlabels-test.mjs` 会自动检查它们都能载入、没有预检错误、导出的 ZPL 里每个码都能被扫码库读回。**这只说明文件本身没问题，打印效果要在真机上看**，结果填到 `docs/print-test-matrix.md`。

用法：「文件 → 载入设计」选一个 `.json`，左侧选好 DPI（与打印机一致）和打印方式，再打印、导出 ZPL 或直发。

| 文件 | 标签尺寸 | 量什么 |
|---|---|---|
| `01-calibration-ruler` | 100×60 | 用卡尺量外框 100.0×60.0、内框 50.0×30.0、刻度间距 10.0mm。误差应 ≤ 0.3mm。四边线条都应完整（驱动打印时检查有没有被裁边、缩放） |
| `02-ladder-code128` | 100×77 | Code128 模块宽 0.125–0.5mm。203dpi 下 0.125 / 0.19 / 0.25 / 0.33 / 0.375 / 0.5 实际为 1 / 2 / 2 / 3 / 3 / 4 个点。记录每档能否扫出 |
| `03-ladder-ean13` | 100×80 | EAN-13 模块宽 0.25–0.5mm（GS1 零售推荐 0.264–0.66，0.25 那档预检会提醒）。有检测仪时记 ISO 等级 |
| `04-ladder-code39` | 100×53 | Code39 模块宽梯度 |
| `05-ladder-itf` | 100×53 | ITF-25 模块宽梯度 |
| `06-cjk-size-ladder` | 100×46 | 中文 1.5–4mm，常规 / 加粗。记录从哪一档开始笔画断开或糊在一起，用来定「最小字号」提醒线（B13） |
| `07-2d-size-ladder` | 100×58 | QR（含中文网址）8–20mm、DataMatrix（含中文）8–20mm。用手机和扫码枪都扫一遍，DataMatrix 要读出「合格证 DM-0001」原文 |
| `08-rotation` | 100×80 | 0 / 90 / 180 / 270° 的文字、Code128、QR，位置与预览一致、都能扫 |
| `09-quiet-zone` | 100×52 | 上排贴边（预检会提醒，预期如此）、下排留足静区。记录贴边的码在真机上是否还能扫 |

浓度 × 速度矩阵：当前界面没有浓度 / 速度设置（`src/zpl.js` 有，界面未接入）。可先在打印机面板上改浓度、速度，各打一张 `02-ladder-code128`，记入测试矩阵。
