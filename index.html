标签打印工具

标签 & 纸张

「每行数量」设 N 按 N 列网格排布；设 0 按宽度自动换行。「从第几个位置开始」可接着用打过一部分的不干胶纸。

打印设置

「到第几条」填 0 表示到最后一条。预览、打印、导出 ZPL 都按这里的范围和份数出标签。打印前会自动预检（条码能否编码、字段是否存在、是否超出标签）。

打印机指令参数（ZPL / TSPL）

导出和直发都按这里的指令语言；TSPL 全部按位图输出，无需打印机中文字库。

打印机（桌面版）

USB 打印机：选「本机打印机按名称」，用上面选中的系统打印机直发（无需共享）；个别新式驱动不接受 RAW 时再改用「共享」。

元素

坐标单位 mm，从标签左上角算起。内容里用 {字段名} 套数据。

数据套打

第一行是字段名，每行数据生成一张标签。支持逗号或 Tab 分隔（可直接从 Excel 复制粘贴）。

可直接导入 .xlsx，或 Excel「另存为 CSV」（UTF-8 / GBK 自动识别），也可复制单元格区域粘贴到上面。
