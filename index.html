标签打印工具

标签 & 纸张

整页套打：「每行数量」设 N 则按 N 列网格排布（如 A4 不干胶多张/页）；设 0 则按宽度自动平铺换行。标签机一般每张一页。

打印设置

「到第几条」填 0 表示到最后一条。预览、打印、导出 ZPL 都按这里的范围和份数出标签；流水号按实际张数逐张递增。

打印机（桌面版）

USB 打印机：在 Windows 打印机属性里设为「共享」，这里填共享名即可直发。

元素

坐标单位 mm，从标签左上角算起。内容里用 {字段名} 套数据。

数据套打

第一行是字段名，每行数据生成一张标签。支持逗号或 Tab 分隔（可直接从 Excel 复制粘贴）。

Excel 文件请在 Excel 里「另存为 CSV」后导入，或直接复制单元格区域粘贴到上面。

变量（打印时输入）

内容里写 {变量名} 引用。勾「打印时询问」的变量，每次打印/导出 ZPL/直发前弹框让操作员输入或从挑选列表里选；数据源里有同名字段时以数据为准。
