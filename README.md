# 标签打印工具

一个纯浏览器运行的标签 / 条码设计与批量打印工具，无需安装，可打印到任意打印机（普通办公打印机或标签机）。全部为原创实现。

## 使用

用 Chrome / Edge 直接打开 `index.html` 即可。

## 功能

- **标签 & 纸张**：自定义标签宽高（mm）、打印精度 DPI（96 / 203 / 300 / 600）、整页套打时的标签间距。
- **元素**：
  - 文字（字号、加粗、字体、对齐）
  - 富文本：同一段内混排**粗体 / 斜体 / 下划线 / 颜色 / 字号**，自动换行、左中右对齐。编辑框带工具条（选中文字点 B / I / U / 字号 / 着色 / 清除）；可「导入 RTF…」（写字板 / Word / WPS 另存为 RTF，含中文 GBK），从 Word / 网页复制粘贴时保留格式。格式以 `[b]…[/b]`、`[size=5]…[/size]`、`[color=#c00000]…[/color]` 等标记保存，可含 `{字段}`；只认这几种标记，数据内容里的标记不会生效。热敏机打印时彩色一律打成黑色。
  - 艺术字：平直 / 上拱 / 下弯 / 波浪排列，弯曲度、字距、描边、空心字、阴影可调；单色热敏机上同样清晰（阴影与正文间自动留白边）
  - 条码：Code128、EAN-13、EAN-8、UPC-A、Code39、ITF-25（均为自写编码；EAN/UPC 少写校验位时自动补上）
  - 二维码：QR Code（L/M/Q/H 纠错）、DataMatrix ECC200（均为自写编码，完全离线；中文用 UTF-8 编码，扫码不乱码）
  - 数字类条码（EAN-13/EAN-8/UPC-A/ITF）会核对校验位：校验位错、含字母时直接报错，不会打出扫不出的码
  - 流水号（起始、步进、补零、前后缀、打印后自动续号）；内容里写 `{#SN}` 可把流水号放进文字、条码、二维码
  - 日期（格式符见下；保质期这类偏移用 `{#DATE+30:YYYY-MM-DD}`）
  - 图片 / Logo（本地上传）
  - 线条 / 边框 / 黑块
  - 每个元素支持任意角度旋转、复制
  - 预览缩放
- **数据套打**：第一行字段名，每行数据生成一张标签。支持逗号 / Tab / 分号分隔（可直接从 Excel 复制粘贴），可导入 CSV（UTF-8、GBK 自动识别，中文版 Excel「另存为 CSV」不乱码）或直接导入 **.xlsx**。
- **内容语法**：
  - 普通文字直接写（可含 `[` `]` 等任意字符）。
  - 插值：`{字段}`，字段名可以是中文、带空格，如 `{品名}`、`{unit price}`、`{表.字段}`。
  - 变量：`{#SN}` 流水号、`{#DATE}` / `{#DATE:YYYYMMDD}` / `{#DATE+30:YYYY-MM-DD}`（+6M 六个月、+1Y 一年）、`{#TIME}`、`{#N}` 第几张、`{#REC}` 第几条、`{#COPY}` 第几份。
  - 打印时输入：在「变量」面板定义变量并勾选「打印时询问」，内容里写 `{变量名}`（见下文「变量」）。
  - 表达式：以 `=` 开头，支持 `[字段]`、`"文字"`（`\"` 转义）、数字、`+` 拼接，以及函数：
    - 文字：`left` `right` `mid` `upper` `lower` `trim` `concat` `len` `replace(s,旧,新)` `padl(s,位数,"0")` `padr`
    - 计算：`add` `sub` `mul` `div` `round(x,位)` `fixed(x,位)` `int`
    - 判断：`if(条件,是,否)` `eq` `ne` `gt` `lt` `ge` `le` `and` `or` `not` `empty`
    - 日期：`today("YYYY-MM-DD")` `date(格式,偏移,"d|m|y")` `adddate([生产日期],18,"m","YYYY-MM-DD")` `fmtdate`
    - 校验位：`mod10("692525384166")`（GS1）、`mod43(s)`（Code39）
  - 日期格式符：`YYYY YY MM DD HH mm ss JJJ`（年内第几天）`WW`（ISO 周）。
  - 例：`=[JYPRICE] + ".00"`、`=fixed(mul([零售价],0.9),2)`、`=if(gt([库存],0),"有货","缺货")`、`{SKU}-{#SN}`
- **保存 / 载入设计**：把当前标签设计导出为 `.json`，下次载入继续用。
- **画布编辑**：
  - 点选、拖动、拖右下角手柄缩放；方向键微调（Shift 加速）
  - **多选**：Shift/Ctrl+点击、在空白处拖出框选、Ctrl+A 全选、Esc 取消；多选后可整体拖动、方向键移动、复制粘贴、删除、置顶/置底
  - **对齐**：单个对象对齐到标签；多个对象彼此对齐（左/中/右/顶/中/底）
  - **等距分布**：选 3 个以上，水平或垂直等间距排开（首尾不动）
  - **成组 / 解组**（Ctrl+G / Ctrl+Shift+G）：成组后点任一成员即选中整组，对齐/分布时整组作为一个整体
- **打印**：一键调起系统打印，两种打印方式：
  - **标签机**（默认）：每张标签单独一页，页面尺寸 = 标签尺寸、无页边距（标签机驱动不会把多张挤在一页或裁边）；
  - **整页**：A4 / A5 / Letter，可设页边距、行列间距、每行数量，并可「从第几个位置开始」（接着用打过一部分的不干胶纸）。
  - 桌面版静默打印同样按标签尺寸 / 纸张出纸。旧设计里设了「每行数量」的自动按整页模式打开。
- **打印前预检**：打印、导出 ZPL、静默打印、ZPL 直发前逐张检查：
  - 错误：条码无法编码（如 EAN 校验位错）、表达式出错、字段找不到。出错的标签只能「取消」或「跳过出错的标签」，不会把「⚠ 错误信息」打到标签上；
  - 提醒：超出标签、静区不足、模块小于 1 个打印点、EAN 尺寸偏离 GS1 推荐、条码被其它内容压住。可继续打印；
  - 预览里字段名写错、表达式出错的元素用红色虚线标出，鼠标悬停看原因（只在屏幕上显示）。

## 示例

`examples/` 下有一个服装吊牌示例（由一份 StrandWare `.qdf` 吊牌模板还原字段与表达式）：

1. 打开 `index.html`，点「载入设计」选 `examples/clothing-tag.json`。
2. 在「数据套打」里点「导入 CSV 文件」选 `examples/clothing-tag.csv`，再点「生成标签」。
3. 预览确认后点「打印」。

坐标 / 字号是估算值，可按实际吊牌微调。

`examples/test-labels/` 是真机测试标签（尺寸校准尺、各码制模块宽梯度、中文小字梯度、二维码尺寸梯度、旋转、静区），用法见该目录 README，测试结果填 `docs/print-test-matrix.md`。

`examples/serial-qr.json` + `serial-qr.csv` 是追溯标签示例：流水号同时进文字和二维码、生产日期 / 保质期自动计算、批号打印时输入、会员价计算。

## 打印设置与流水号

- **打印范围 / 份数**：左侧「打印设置」可指定从第几条到第几条记录、每条打几份；预览、浏览器打印、导出 ZPL 三处一致。范围填反（如从 5 到 3）时提示错误、不出纸。
- **流水号**：每张递增（同一条记录打多份时每张不同）；预检时跳过的标签不会让后面的号错位。
- **打印后自动续号**：流水号勾选该项后，每次打印/导出 ZPL 并确认成功，起始值自动顺延到下一个号，下次接着编号、不重号（取消则不变）。
- **自动保存**：每次改动自动保存在本机，关闭软件或意外退出后重新打开，设计自动恢复。

## 变量（打印时输入 / 挑选列表）

左侧「变量」面板定义变量，内容里用 `{变量名}` 引用（与数据字段写法相同）：

- **类型**：文本、挑选列表（每行一项，打印时下拉选择）、日期、数字；可设默认值、提示文字、必填。
- **打印时询问**：勾选后，每次打印、导出 ZPL、静默打印、ZPL 直发前都会弹框让操作员输入或选择，取消则不打印；上次的值会预填。
- 数据源（CSV/数据库）里有同名字段时以数据为准；变量定义随设计文件保存，当前值记在本机。

## 斑马机直打（ZPL）

「文件 → 导出 ZPL（斑马机）」生成 Zebra 打印机指令（`label.zpl`），可直接发给 ZT410 等斑马机：

- 坐标、尺寸按斑马机真实点距换算（203dpi=8 点/mm，300dpi=12 点/mm，600dpi=24 点/mm）。
- **所见即所得**：条码、二维码、文字（含中文）、段落、图片/Logo 全部用与屏幕预览**同一套几何**栅格化成整点位图（`^GFA`），打印机无需中文字库，也不依赖各型号固件对条码指令的差异；条码模块宽对齐到整数点，保证可扫。
- 旋转（90°/180°/270° 及任意角度）的元素按预览同样的旋转输出；图片/Logo 经抖动处理成黑白点阵。
- 线框/椭圆用打印机原生 `^GB`/`^GE` 指令；同一份内容在多张标签里重复出现时只下载一次（`~DG` + `^XG`），减少传输量。
- 位图压缩可选：**Z64**（zlib+Base64，新款斑马机，体积最小）或 **ACS**（兼容所有斑马机）。示例「合格证」每张 300dpi 约 3 KB（Z64）/ 7 KB（ACS），串口 115200 波特率下每张约 0.3 秒。
- 每次改动都会用独立的 ZPL 渲染器重绘输出、逐元素比对位置，并用扫码库扫出条码内容验证。
- 多条数据记录 → 多张标签。

**桌面版可直接发送**（左侧「打印机」面板或「文件 → ZPL 直发打印机」），三种方式：

| 方式 | 适用 | 填写 |
|---|---|---|
| 网络打印机 | 有网口的斑马机 | IP（端口默认 9100） |
| 本机共享打印机 | USB 连接的打印机 | 在 Windows 打印机属性里设为共享，填共享名 |
| 串口 | 串口连接（如 COM1） | COM1 / COM2 …（使用系统串口设置的波特率） |

桌面版还能列出本机打印机，选定后「打印到此打印机」静默出纸，不必每次弹打印对话框。

> 主进程（`src/rawprint.js`）已支持按打印机名 RAW 直发、串口波特率、读取打印机状态与分辨率，界面入口尚未接入。

## 桌面安装版（本地运行 + 连数据库）

除了直接打开 `index.html`，本项目也可打包成 Windows 安装版客户端（基于 Electron），本地安装运行，并直接连数据库做套打。

支持的数据库：**SQLite、Microsoft Access(.mdb/.accdb)、MySQL、PostgreSQL、SQL Server**。

### 方式一：下载已打包好的安装程序（推荐）

仓库已配置 GitHub Actions 自动在 Windows 上打包（Electron 44）。每次打包前跑全部自检，打包后还会**真机启动安装版**做一次自检（窗口、ZPL 引擎、网络直发、5 种数据库驱动），任何一项不通过都不出包：

- 在 GitHub 仓库页 **Actions → Build Windows Installer**，手动运行（Run workflow），完成后在该次运行页底部下载 `label-print-tool-windows` 产物，解压得到 `.exe` 安装程序。
- 或推一个 `v` 开头的标签（如 `git tag v0.2.0 && git push --tags`），会自动在 **Releases** 页发布安装包，直接下载。

### 方式二：在你的 Windows 电脑上自己构建

> 需先装 [Node.js](https://nodejs.org)（建议 22+）。

```bat
npm install
npm run dist
```

完成后在 `dist/` 目录得到安装程序（`.exe`），双击安装即可。开发调试用：

```bat
npm start
```

> 数据库驱动列为可选依赖：某个驱动在你的机器上编译不成功，不会中断安装，只是该类型数据库暂不可用，其它功能照常。

### 连数据库套打

1. 打开客户端，在「数据库」面板选类型、填连接信息（Access/SQLite 选本地文件，其余填主机/账号/库名）。
2. 点「测试连接」，再填一条 `SELECT` 查询，点「取数生成标签」。
3. 查询返回的每一行生成一张标签，列名即可在元素里用 `[列名]` 或 `{列名}` 引用。

- **浏览表和字段**：连接后点「浏览表」，选一个表会自动生成查询（表名按各库规则转义），字段列成 `{字段}` 标签，点一下即复制。
- **中文字段名**：`{品名}`、`{零售 价}` 这类中文、带空格的字段名可直接引用（CSV 表头同样适用）。
- **密码安全**：数据库密码交给 Windows 系统加密（DPAPI）后保存，只有本机本用户能解开；系统无法加密时不保存密码。旧版本保存过的明文密码会在打开时自动改为加密保存。

- **只读**：只允许 `SELECT` / `WITH` 查询，防止误执行修改数据的语句。
- 日期按本地时间取值（不会因时区少一天）；图片字段（PNG/JPEG/GIF/BMP）可直接用作图片。

> Access 连接需本机已安装「Microsoft Access Database Engine / ODBC 驱动」。本软件是 64 位，需装 64 位驱动（装了 32 位 Office 时可用 `/quiet` 参数强制安装 64 位驱动）。
> 各数据库驱动（better-sqlite3 / odbc / mysql2 / pg / mssql）为原生模块，由 `npm install` 自动编译安装；没用到的类型即使未成功安装也不影响其它功能。

## 自动测试

- `npm test`：编码器（二维码/DataMatrix 用独立解码器扫回）、ZPL 压缩往返、直发、数据源。
- `npm run test:e2e`：21 组界面与打印端到端测试（Playwright 驱动真实页面）。打印结果用独立的斑马渲染器（Zebrash）还原成出纸图像，逐元素比对位置、逐像素比对预览，再用扫码库扫出条码内容核对。可只跑部分：`node tests/e2e/run.mjs rich wordart`。
- 每次推送 GitHub 自动跑以上全部（Actions → Test）；失败时可下载截图与生成的 ZPL。

## 编码器正确性

所有条码/二维码编码器均为自写，无第三方依赖、完全离线，由仓库内测试用独立解码器（jsQR、ZXing、zxing-cpp）扫回校验：
一维码六种全部覆盖并验证错误数据被拒绝；QR 覆盖版本 1–40、四档纠错、中文 UTF-8；DataMatrix 覆盖全部 23 档尺寸及中文。
ZPL 测试会把生成的指令还原成打印点阵再扫码（含 90/180/270° 旋转），保证打印机实际打出的码能扫。

```bat
npm test          :: 全部单元测试（编码器、表达式、预检、ZPL 点阵扫码、数据来源、直发）
npm run test:e2e  :: 端到端测试：浏览器 + 桌面版连模拟网络标签机（需要 Playwright；Linux 无桌面用 xvfb-run）
```

每次推送 / PR 自动跑测试；打包前也会先跑，未通过则不出安装包。

## 代码结构

| 文件 | 内容 |
|---|---|
| `index.html` | 界面、预览、交互、打印流程（浏览器 / 桌面共用） |
| `src/barcodes.js` | 条码 / 二维码编码器 |
| `src/textdata.js` | 内容求值、变量、日期、表达式函数、CSV 解析、编码识别 |
| `src/job.js` | 打印序列（范围 / 份数）、流水号、打印前预检 |
| `src/zpl.js` | ZPL / TSPL 生成（另一开发线的实现，有单元测试；界面目前用 `index.html` 里的 ZPL 栅格化） |
| `src/xlsx.js` | .xlsx 读取 |
| `src/datasource.js` / `src/rawprint.js` | 桌面版：数据库；原始指令直发（网络 / 按名称 / 共享 / 串口）与打印机状态 |

`src/*.js` 都是普通脚本：浏览器里直接 `<script src>` 使用（双击 `index.html` 即可运行），Node 测试里 `require`。
浏览器里以命名空间提供：`Barcodes.*`、`TextData.*`、`Job.*`、`XLSX.*`。界面目前加载 `barcodes.js`、`textdata.js`、`xlsx.js`、`job.js`。
