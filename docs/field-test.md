# 真机现场测试单

云端自动验收（`docs/acceptance-report.md`）已覆盖软件内部的全部判定：用独立渲染器出纸、独立解码器扫码、打印成 PDF、真实数据库、模拟网络标签机。**打印机硬件和扫码设备只能在现场验证**，下面每一项都要实测并在「结果」栏签字。全部通过才算可以投入生产。

## 准备

- **软件**：Windows 安装包（GitHub Actions「Build Windows Installer」生成的 `label-print-tool-windows`）。安装后打开一次，确认能正常启动、没有报错。
- **打印机**：手头有哪些就测哪些，至少一台斑马机（ZPL）和一台国产机（TSPL），分别记下型号、分辨率、连接方式。
- **标签纸**：间隙纸 60×40mm；条件允许时加测黑标纸、A4 不干胶。
- **扫码设备**：激光一维枪、二维影像枪、手机（微信扫一扫），三类都要有。
- **量具**：卡尺或钢尺；有条码检测仪时一并使用。
- **测试数据**：仓库里的 `examples/clothing-tag.json` + `.csv`、`examples/serial-qr.json` + `.csv`。

| 2.3 | GS1：扫码枪开启 GS1 / FNC1 输出后，读出的 AI 和数据正确 | |
