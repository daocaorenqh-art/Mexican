## B. 预览 / 浏览器打印 / ZPL 三处一致（P0–P1）

- **B1 ZPL 忽略旋转**（P0）。`buildZPL`（`:1236-1274`）完全没用 `el.rot`。90° 的倍数用各指令的方向参数 N/R/I/B（或 `^FW`）；文字位图在 canvas 里旋转；任意角度整体栅格化成 `^GFA`。 ✅ `22450d4`（任意角度整体栅格化）
- **B2 ZPL 丢掉图片**（P0）。switch 里没有 `image` 分支，Logo 打不出来。改成 canvas → 阈值或 Floyd–Steinberg 抖动 → `^GFA`。 ✅ `22450d4`
- **B3 段落在 ZPL 里用内置字体 `^A0`，中文打不出**（P0，`:1253-1254`）。改成按预览的同样规则折行后栅格化；可选使用打印机自带的中文字体（`^A@`/`^CW`）。 ✅ `22450d4`（栅格化）
- **B4 实心椭圆在 ZPL 里只画轮廓**（`:1267-1268`）。`fill` 时把线宽设为 `ceil(min(w,h)/2)`。 ✅ `5a1bad8`（实心椭圆改为位图输出；另修 ACS `!` 歧义）
- **B5 Code128 的 ZPL 没指定模式**（`:1255`，`^BCN,h,Y,N,N`，mode 默认为 N）。按 Zebra 手册，不带调用码时打印机用子集 B 编码，纯数字会比预览（用的子集 C）宽很多，可能出界；数据里的 `>` 还会被当成调用码。改法二选一：加 `,A` 自动模式，或按本项目编码器的子集切换生成 `>;`/`>:` 调用码，保证宽度和预览一致。**【待真机/Labelary 确认宽度差异】**
- **B6 Code39**：预览转了大写（`:633`），ZPL 发的是原文（`:1259`）。**B7 ITF**：预览把奇数位补了前导 0（`:646`），ZPL 发的是原数（`:1260`）。两条都改成统一规范化。
- **B8 ZPL 里的 QR/DM 由打印机自己编码**（`:1261-1264`），版本和尺寸可能与预览不同，放大倍数是按我们的版本算的。另外 `zEsc` 把 `^`、`~` 换成了空格，数据被改了（比如带 `~` 的网址）。改法：用 `^FH` 十六进制转义；另提供「按本项目矩阵输出 `^GFA`」选项，做到严格所见即所得。QR 的 `^FO` 纵向偏移需要实测。
- **B9 颜色和反白**（白字黑底等）不进 ZPL，可用 `^FR`/`^LRY` 实现。
- **B10 文字对齐基本无效**：`text` 的居中/右对齐在预览里没有宽度可对齐（`:800`），ZPL 里也被忽略。需要定义锚点语义（x 是左边、中心还是右边），或给文字一个框宽。
- **B11 浏览器/驱动打印的页面尺寸不对**（P0，研究重点）。`@page{margin:8mm}`（`:101`）没设 `size`，标签之间也没有分页，在标签机驱动上会多张挤在一页、四周被 8mm 边距裁掉；Electron 静默打印（`main.js:91`）也没传 `pageSize`。改法：分两种模式。
  - **标签机模式**：`@page{size:W mm H mm;margin:0}`，每张标签 `break-after:page`，Electron 传以微米为单位的 `pageSize`。
  - **整页模式**：A4/Letter 加页边距、行列间距模板，并支持「从第 N 个标签位开始」。
  - 验收：`printToPDF` 输出的页数等于张数，页面尺寸等于标签尺寸。 ✅ `059c2bc`（Chromium 打印样式 PDF 验证；Electron printToPDF 与真机待测）
- **B12 驱动打印时与打印点对齐**：条码模块宽已经对齐到打印点，但元素的原点没对齐。用 D4 的流程实测各 DPI 下模块宽的误差，再决定是否把原点也对齐到点。
- **B13 小字号文字**：`textGF` 用 128 作阈值，小字号笔画可能断。用 D6 的测试标签实测 1.5–4mm 中文的可读性，定一个最小字号警告线。DPI 选项补上 600，选 96 时导出 ZPL 给出警告。

## C. 打印机通信与直打（P1）

- **C1 USB 免共享直发**：目前 USB 机必须在 Windows 里设共享（`src/rawprint.js:44`，`copy /b \\localhost\共享名`）。改成按打印机名直接走 Windows 后台打印 RAW（OpenPrinter / StartDocPrinter(RAW) / WritePrinter），可用 PowerShell `Add-Type` P/Invoke 或原生模块实现。打印机名继续白名单校验，数据走临时文件或 stdin，不拼进命令行。
- **C2 串口参数**：`copy /b COMn`（`:64`）用的是系统默认波特率，和打印机不一致时打出乱码。增加波特率、校验位、数据位、停止位设置（先执行 `mode COMn BAUD=…`，或改用 serialport）。
- **C3 打印机状态与 DPI 自检**：通过 TCP 发 `~HS` 读缺纸、缺碳带、开盖、暂停状态，打印前后各查一次；用 `~HI` 读型号和分辨率，**设计 DPI 和打印机实际 DPI 不符时阻止发送**（203 的设计打到 300 的机器上尺寸会缩到约 2/3）。
- **C4 打印参数配置**：浓度 `^MD`/`~SD`、速度 `^PR`、热敏/热转印 `^MT`、间隙/黑标/连续纸 `^MN`、上下偏移 `^LT`、左右偏移 `^LS`、原点 `^LH`、撕纸/剥离/切刀 `^MM`。做成「打印机配置档」，和打印机绑定保存。
- **C5 大批量性能**：`buildZPL` 把所有标签拼成一个大字符串，每张标签的每段文字都重新栅格化成不压缩的十六进制 `^GFA`，几千张时可达数百 MB。按收益依次做：
  1. 静态文字的位图只算一次，缓存复用；
  2. 静态图形用 `~DG` 存进打印机，再用 `^XG` 调用，或用 `^DF`/`^XF` 模板配 `^FN` 只发变量；
  3. 位图用 Z64（zlib + base64 + CRC）或 ACS 压缩；
  4. 没有逐张变量时用 `^PQn` 出份数，流水号用 `^SN`；
  5. 分批发送，带进度条和取消。
- **C6 打印作业管理**：显示进度、可取消、失败批次可重试、卡纸后「从第 N 条续打」。浏览器打印一次渲染上万张 DOM 会卡死，也要分批。
- **C7 多种指令语言**：抽象出「打印机语言驱动」接口，形如 `build(design, rows, profile) → bytes`，ZPL 作为第一个实现。优先补 **TSPL**（TSC、佳博、芯烨，国内最常见），其次 EPL2、DPL、SBPL、CPCL。
- **C8 TSPL 的中文**：要么把文字栅格化成 `BITMAP` 指令，要么用打印机自带字体（需要 GB 编码，在主进程里转码）。

## D. 打印测试体系（本任务的研究重点，P1）

- **D2 逻辑单元测试**：覆盖表达式、CSV 解析、`printList`（范围、份数）、流水号、日期格式。前提是先完成 H1 的模块化拆分。
- **D3 ZPL 黄金样本测试**：对示例设计生成的 ZPL 做快照；再在有网络的本机或 CI 上用 Labelary 把 ZPL 渲染成 PNG，用 ZXing 逐个读回条码并比对期望值，与同 DPI 的预览点阵做像素差（允许一定容差）。

## E. 对标 LABEL MATRIX 补齐功能（P2）

- **E1 打印时输入**（Prompt）：打印前弹出表单，字段有类型（数字/日期/下拉）、校验、默认值、必填，内容里用 `{?批号}` 引用。
- **E2 统一变量体系（关键）**：流水号和日期现在是独立元素（`:846-853`），**不能放进条码或二维码的内容里**，序列号条码、追溯码都做不了。改成变量：`{#SN}` 或具名计数器、`{#DATE:YYYYMMDD}`、`{#TIME}`、`{?输入}`，任何元素和表达式都能用。
- **E3 流水号增强**：按记录递增还是按张递增、每 N 张递增一次、字母数字/十六进制/36 进制、按日清零；计数器存到应用数据目录（多个设计共用），多人同时用时可放进数据库，防止重号。
- **E4 日期增强**：偏移量（今天 + N 天/月，用于保质期）、`YY`/`M`/`D` 等格式符、周数、「2026年10月20日」写法、儒略日。
- **E5 表达式函数** 【已复现：`=[价格]+1` 得到 "91"】：保留 `+` 作拼接（兼容现有设计），新增 `add` `sub` `mul` `div` `round` `fixed(n,2)` `if` `padl` `padr` `replace` `len` `today` `adddays` `mod10` `mod43`；字符串字面量支持转义。
- **E6 GS1 系列**：GS1-128（FNC1、应用标识符、带括号的人眼可读文字）、GS1 DataMatrix（FNC1 码字 232）、GS1 QR、GS1 Digital Link，并按 AI 字典校验，例如 (01) GTIN-14 校验位、(17) 日期为 YYMMDD。
- **E7 更多码制**：UPC-E、EAN/UPC 2 位或 5 位附加码、带保护框的 ITF-14、Code93、Codabar、PDF417、Aztec、MaxiCode；DataMatrix 长方形尺寸（适合小吊牌）；DM 的 C40/Text/Base256 和 QR 的数字/字母数字模式可以缩小码图（【已复现】40 位纯数字现在是 v3，用数字模式只要 v2）。**每个新编码器都必须过独立解码器的 CI 校验**，延续项目现有规则。
- **E8 文字适应框**：自动缩小字号以放进框内、最大行数、超长显示省略号、锚点对齐，溢出时告警。
- **E9 动态图片**：图片路径或网址来自字段（如 `C:\img\{SKU}.png`），或读数据库里的 BLOB；配阈值和抖动参数。
- **E10 整页模板库**：A4 不干胶模板（页边距、行列间距）、「从第 N 个标签位开始」、常用标签规格库。
- **E11 车间「只打印」模式**：选模板 → 输入或选记录 → 打印，设计被锁定，进入设计模式可设密码。
- **E12 打印日志和追溯**：记录谁、何时、哪个模板、哪些记录、几张、流水号区间、哪台打印机；能从日志补打，并防止流水号重复。
- **E13 记录选择**：数据表格视图，可搜索、筛选、勾选，只打选中的记录；可用某个「数量」字段作为该条记录的打印份数。
